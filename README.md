# Luminous Robots Writing

A reusable writing skill for drafting, revising, and reviewing research text on luminous robots, distributed algorithms, and grid exploration.

The skill helps improve clarity, consistency, and precision while preserving technical meaning, notation, and LaTeX formatting.

## What it includes

- A glossary of terms and notation.
- Writing guidance for introductions, models, methods, results, and proofs.
- Three newly written before-and-after examples.
- Rules for preserving technical meaning and LaTeX.
- Instructions for returning rewrites and actionable reviews.

The skill is self-contained. Access to the original paper or LaTeX project is not required.

## How to use it

Give your writing assistant [SKILL.md](SKILL.md), or a link to that file, together with your draft and request.

For example:

> Follow the instructions in SKILL.md to revise the LaTeX below.
> Improve clarity while preserving all assumptions, claims, notation,
> commands, labels, and citations. Return paste-ready LaTeX and flag
> technical ambiguities separately.

For a review:

> Review this section using SKILL.md. Identify each relevant passage,
> explain the issue, and suggest a specific edit. Separate language
> improvements from technical questions requiring author review.

## Adapting to new research

The current draft determines the model assumptions, definitions, notation, and claims.

The skill also applies to grids without obstacles. It does not require the obstacle assumptions or robot settings of the reference paper.

Simulation evidence must remain distinct from proved results. Consistently defined new terms and notation should be preserved.
